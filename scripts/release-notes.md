Table Score keeps scores for 2–8 players or teams, saves each change on the device, and supports rounds, undo, game history and text sharing in English and Russian.

This signed build passed unit tests, Android lint and the create/score/undo/process-restart/export scenarios on Android API 24 and API 36 in GitHub Actions. See the attached signature and package verification reports.

This is a testing release. Advertising activation and Google Play moderation are external steps; their completion is tracked in the release manifest.
